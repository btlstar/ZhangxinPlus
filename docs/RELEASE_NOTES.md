# ZhangxinPlus 0.2.0

Windows x64 独立图形工具；插件核心仍为已验证的 0.1.5，适配掌心资源 92217。

## 新增

- 选择游戏目录、查看状态、安装 / 更新、还原。
- 自动识别与游戏目录匹配的 AkagiPlus 现有备份，其他安装使用独立备份。
- 后台处理较慢操作，显示错误原因；操作中避免关闭窗口。
- 便携包附带运行依赖，无需另装 Python、AkagiPlus 或 Proxifier。

## 使用

完整解压 `ZhangxinPlus-0.2.0-windows-x64.zip`，运行 `ZhangxinPlus.exe`。先完成官方资源更新并退出游戏，再安装；之后在游戏原有界面换装。需要停用时退出游戏并还原。

核心支持角色、皮肤、星标、桌布、麻将牌、立直棒、特效、表情、音乐、称号、头像框及装扮方案。头像与语音未完整适配。仅改变本机显示，不修改服务器资产或养成。

AI 请使用 AkagiPlus。0.2.0 保持插件核心与 AkagiPlus v3.8.0-plus.2 兼容。未知官方资源更新会拒绝覆盖；请保留原始备份。

独立窗口的「安装 / 更新 → 还原游戏文件 → 安装 / 更新」已通过用户实测。另附 ZIP 的 `.sha256` 校验文件。本版为首次独立工具预发布版。
