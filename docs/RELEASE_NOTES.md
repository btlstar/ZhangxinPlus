# ZhangxinPlus 0.2.1

掌心麻将 Windows x64 本地装扮插件与独立图形管理工具，适配官方资源 **92217**，插件核心版本 **0.1.5**。

## 本次更新

统一 README、窗口和发布说明，将项目作为独立装扮插件介绍。工具提供目录选择、状态查看、安装 / 更新及还原，随包包含运行依赖。

## 下载使用

完整解压 `ZhangxinPlus-0.2.1-windows-x64.zip`，运行 `ZhangxinPlus.exe`。先完成官方资源更新并退出游戏，再安装；随后在游戏原有界面选择装扮。需要停用时退出游戏并还原。

支持角色、皮肤、星标、桌布、牌背、麻将牌、立直棒、特效、表情、音乐、称号、头像框及装扮方案，按账号保存本地选择。头像与语音尚未完整适配。本地装扮不增加服务器资产或真实养成进度。

安装前核验已适配资源与文件摘要，先备份再替换；未知官方更新会停止覆盖，请保留原始备份。本版为预发布版，另附 ZIP 的 SHA-256 校验文件。

独立窗口安装、还原及重新安装已通过用户实测；0.2.1 对应界面与文案更新，插件核心沿用已验证的 0.1.5。
