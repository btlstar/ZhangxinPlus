# ZhangxinPlus · 掌心 Plus

掌心麻将 Windows 客户端的本地装扮插件与独立图形管理工具。工具 **0.2.0** 沿用已实测的插件核心 **0.1.5**，适配官方资源 **92217**。

本地候选版正在准备发布；GitHub Release 尚未发布。完整解压便携包后运行 `ZhangxinPlus.exe`，不需要另装 Python、AkagiPlus 或 Proxifier。

## 使用

1. 正常启动掌心并完成官方资源更新，然后退出游戏。
2. 打开工具，选择包含 `zhangxinmj.exe` 的安装目录，点击「查看状态」。
3. 点击「安装 / 更新」，完成后正常打开掌心。
4. 在游戏原有界面选择角色、皮肤及装扮。需要移除时，先退出游戏，再点击「还原游戏文件」。

安装前会核验版本和文件摘要，先备份再替换两个脚本资源包。未知资源更新、备份损坏或文件被其他工具修改时会停止覆盖。游戏运行时拒绝安装和还原，不强制结束进程。

## 功能与范围

- 角色、皮肤、星标、桌布、牌背、麻将牌、立直棒、特效。
- 表情物品、觉醒表情、本地音乐、称号、头像框、牌桌边框。
- 装扮方案的创建、保存、使用、改名与删除，选择按账号保存在本机。
- 自身友人房卡片和牌桌资料应用本地选择，其他玩家资料保留。

只改变本机显示，不增加服务器拥有物、货币、抽取、赠礼或真实养成进度；不保证他人视角可见。头像与语音仍未完整适配。官方更新后可能需要重新适配。

## 与 AkagiPlus 共用

工具会自动复用与所选游戏目录匹配的 AkagiPlus 恢复记录；不同安装目录使用独立备份。不要删除备份，直到已完成还原。已有 AkagiPlus 用户无需先还原再重复安装。

工具版本与插件核心版本独立计数。0.2.0 没有修改 0.1.5 Lua 核心，保持与 AkagiPlus `v3.8.0-plus.2` 的资源核验兼容。

AI 需要使用 [AkagiPlus](https://github.com/btlstar/AkagiPlus/releases/tag/v3.8.0-plus.2)。已实测普通立直友人局三麻、四麻；其他玩法、中途恢复及自动操作尚未支持。独立工具只管理装扮插件，不包含 AI 界面或服务。

## 配置与恢复

- 工具只在 `%LOCALAPPDATA%/ZhangxinPlus/gui.json` 记住所选游戏目录。
- 备份优先复用匹配的 `%APPDATA%/akagiplus/zhangxinplus` 或旧独立版记录；新安装使用 `%LOCALAPPDATA%/ZhangxinPlus/installs/<安装标识>`。
- 窗口显示本次备份位置，并提供打开目录按钮。
- 本地装扮选择保存在游戏本地数据中；还原脚本不会清除这些选择。

不要用来自另一个游戏目录的恢复记录覆盖当前安装。工具遇到无法核验的文件会停止并显示原因。

## 源码与构建

Python 3.12、Windows x64。安装 `requirements-build.txt` 后运行 `python package.py`。依赖锁定见 `requirements-lock.txt`；构建产物在 `dist`。

开发检查：`python -m unittest test_manage test_service test_gui`。如需检查客户端实际 Lua，再运行 `python test_lua.py <游戏目录> --staged <暂存资源目录>`；该检查使用本机游戏库，不分发游戏资源。
